# 浏览器兼容性修复需求

## 范围

修复前端在不同浏览器中因直连/后端中转通道状态不一致而出现的模型获取、生图、改图、文件上传和聊天请求差异。视频继续使用后端中转。安装并使用后端 `pytest` 与前端 `fake-indexeddb` 依赖。

## 已确认事实

- `frontend/js/api.js` 在每个浏览器的 `localStorage` 中缓存上游通道状态。
- 缓存没有过期机制；不同浏览器可能长期保留不同结果。
- 上游 CORS 预检已用真实请求验证正常。
- 上游直接生图、改图和视频链路已用测试密钥验证成功；视频能力依赖所用密钥。
- 用户授权修改代码、安装依赖，并进行两轮真实测试。

## 验收标准

- 过期的通道缓存会重新探测，不会永久锁定某一通道。
- 浏览器级网络/CORS 失败会回退到中转；真实 HTTP 错误保持原错误，不被误判为跨域。
- 直连图片 URL 下载失败时可回退到中转。
- 模型列表、聊天、生图、改图、视频和本地文件上传的既有请求格式不被破坏。
- 自动化测试通过；两轮真实 HTTP/浏览器可执行性测试如实记录通过、失败或阻塞。

## 排除项

不改上游服务、不保存 API Key、不部署生产、不提交 Git，除非用户另行授权。
